# 📊 WhatsApp Chat Analyzer

A **WhatsApp Chat Analysis Web App** built using **Python** and **Streamlit** that allows users to upload their WhatsApp chat file and get detailed insights about the conversation.

This project performs **data analysis and visualization** on WhatsApp chats such as message statistics, user activity, emoji analysis, and word cloud generation.

## 🚀 Features

* 📈 **Total Message Statistics**
* 👤 **Most Active Users**
* ☁️ **WordCloud Visualization**
* 😂 **Emoji Analysis**
* 📅 **Timeline Analysis (Monthly & Daily)**
* 🔥 **Activity Heatmap**
* 📊 **Most Busy Day & Month**
* 📎 **Media and Link Sharing Analysis**

## 📥 How to Use

1. Export your WhatsApp chat:

   Open WhatsApp → Chat →
   **More Options → Export Chat → Without Media**

2. Upload the `.txt` file into the web application.

3. The app will automatically analyze the chat and display insights.

---

## ▶️ Run the Project Locally

Install required libraries:

```
pip install -r requirements.txt
```

Run the Streamlit application:

```
streamlit run app.py
```
